# Midlife Purchase Provider

Provider for purchase and mid-of-life data.

It contributes fields such as:

- `energy_label`
- `repairability_score`
- `expected_lifetime_years`
- `purchase_price_eur`
- `warranty_years`
- `specifications`
- `maintenance_schedule`
- `repair_history`

Demo product:

```text
WM-BOSCH-001
```

Metadata endpoint:

```text
/.well-known/circthread-service
```
