# Recycling EOL Provider

Provider for end-of-life and recycling data.

It contributes fields such as:

- `materials`
- `hazardous_substances`
- `disassembly_instructions`
- `recycling_instructions`
- `disposal_instructions`
- `recyclability_pct`
- `residual_value_eur`

Demo product:

```text
WM-BOSCH-001
```

Metadata endpoint:

```text
/.well-known/circthread-service
```
